# Alternate String Combiner

A simple and user-friendly web application that takes two strings as input and combines their characters alternately into a single string.

## 📌 Project Overview

The **Alternate String Combiner** is a web-based application developed using HTML, CSS, and JavaScript.

The application accepts two strings from the user and combines them character by character in an alternating order.

### Example

If the user enters:

- First String: `ABC`
- Second String: `123`

The output will be:

```text
A1B2C3
